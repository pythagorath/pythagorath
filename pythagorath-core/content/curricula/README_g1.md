# مناهج الرياضيات — **الصف الأول** (مصادر مرجعية دائمة)

**منفصل تماماً عن الصف الثاني** (`README.md` فصل١، `README_s2.md` فصل٢). كل ملفات الصف الأول تُوسَم **`_grade1`/«صف1»** لئلا تختلط بالصف الثاني.
الهدف: حقبة صفٍّ كاملة كالصف الثاني (مصادر → مخزون → مسارات → ودجات → محتوى) — **بالطريقة المُتعلّمة** (الفهرس الكامل + النهاية، لا أوائل الصفحات).

## 🛡️ البروتوكول الإلزامي لكل وثيقة
1. **تأكيد الدولة + الصف + الفصل:** أنه **الصف الأول** فعلاً (لا الثاني)، والفصل الأول أو الثاني صراحةً (درس التباس الإمارات/التشخيص).
2. **الفهرس الكامل + صفحة النهاية** (آخر وحدة/فصل) — تأكيد العدد الكلي بدليل صفحة.
3. **إن مصوّر بلا نص:** ترميز صوراً وقراءة بصرية. لا تخمين.
4. المحاور والأهداف الكاملة.
5. الحفظ مرجعاً موسوماً `_grade1` + تحديث المتتبّع.

> **بُعد الصف محكم:** عند البناء، الصف الأول **وحدات منفصلة بـ`grade_id` خاص**؛ عقده تُربط بصف١ ومساراتها القطرية → يرثها البُعدان تلقائياً. **لا تُخلَط أكواد صف١ بصف٢** (مفجّر الكود محلول بالتصفية القُطرية+الصفّية والفهرسة بالمعرّف). **لا اشتقاق حتى تكتمل الست.**
