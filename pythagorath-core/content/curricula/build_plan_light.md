# المحاور الخفيفة (P/Z/R/S) — الخطة والمنفَّذ — **إغلاق الصف الثاني الفصل الأول**

**النموذج:** مخزون مشترك + مسارات. وحدة جامعة «الأنماط والتهيئة وحل المسائل». ودجة جديدة واحدة (`pattern`) + إعادة استخدام `shape-pick` + نصّي. البوابات/القفل/المسارات/الودجات الـ١٧/v2 لم تُمسّ.

## المراجعة الصارمة (خفيف ≠ بلا تدقيق)
- **P:** «عددي» و«شكلي» تمثيلان لفعل واحد (إكمال نمط)، متمايز عن القفز (يشمل المتكرر/المتنامي) → عقدة، تعميم.
- **Z:** تصنيف زوجي/فردي فعل واحد، **يعتمد على N4** (القفز بـ٢ يؤسّس الزوجية) → عقدة، تعميم.
- **R:** «تصنيف» (فرز منطقي) و«تموضع» (علاقة مكانية) **فعلان مختلفان** → **عقدتان** (لا دمج بعائلتين مزيّفتين).
- **S:** نمذجة لغوية رمزية. «خطوة»/«خطوتان» نفس الفعل لكن **المسار يفصلهما** (خطوة عند الست، خطوتان عند ثلاث) → **عقدتان** كـ V1/V3.
- **كلها تعميم مصرّح** (فعل واحد بحالتين) — لا عائلتين مزيّفتين.

## الودجة الجديدة (واحدة فقط)
**`pattern`** — متتالية بطاقات (أعداد أو أشكال SVG) بفراغ «؟» + خيارات للتالي؛ يُخرج القيمة المختارة. مبرّرة: `sequence` تُكمل خطوة ثابتة فقط (لا المتكرر/المتنامي)، و`shape-pick` تعرض مثيراً مفرداً لا متتالية. معزولة كالـ١٧.

## الاعتمادات والمسارات (انغلاق محقَّق)
`N4→Z` · `D1→S1` و`D2→S1` · `S1→S2`. P/R1/R2 قواعد مفتوحة. المسارات أعلاه — مختبَرة لكل دولة.
> غموض SA/KW مسجّل حيث ينطبق.
