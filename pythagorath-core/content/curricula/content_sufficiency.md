**المعايير (من المحرّك):** `FAMILIES_REQUIRED=2` · `GENERALIZATION_REQUIRED=2` · **`FLUENCY_WINDOW=5`** · عتبة ٠٫٨ + سرعة.
- **الفهم:** يمرّ بعائلتين أو بندَين متمايزين → **الـ٥٦ عقدة كلها تمرّ الفهم اليوم.**
- **الطلاقة:** نافذة ٥ تعيد تقديم أسئلة العقدة. **عقدة < ٦ أسئلة → النافذة تُكرّر البنود → حفظٌ لا طلاقة.**

## ✅ المرحلة ١ — العمود الفقري (الحساب) مُنفَّذة
**٢٩ عقدة في وحدة الحساب مُلئت إلى ٨/عقدة** عبر `SUPPLEMENT` (مولّدات تحسب الجواب وتُنسّق الأرقام الهندية — تُزيل خطأ الحساب/الكتابة، لا تمسّ العقد الأصلية).
- **الأسئلة: ١٨٠ → ٣٠٩** (+١٢٩).
- **المبادئ مطبَّقة ومُختبَرة:** تنوّع حقيقي في القيم (مطالبات فريدة، نافذة-٥ ترى قيماً مختلفة) · **تنويع الفعل داخل العائلة** للرمزية (F11/F12/F13 تخلط +/−) · العائلات/الحالات مصونة (بوابة الفهم سليمة) · العزل (الودجة تُخرج، البوابة تصحّح؛ الرمزية نصّية) · أرقام هندية، نطاق صف-ثاني، فصحى محايدة.
- **اختبارات `test_content.py`:** (أ) كل عقدة عمود-فقري ≥٨ بمطالبات فريدة وأجوبة متنوّعة، (ب) العائلات مصونة (تعدّد/تعميم)، (ج) الرمزية تنوّع الفعل، (د) كل الأجوبة المولّدة صحيحة (`grade` يمرّ).

**العمود الفقري صار 🟢 جاهزاً للتجريب الحقيقي** (طلاقة صادقة لا حفظ).

## المتبقّي — المرحلة ٢ (٦/عقدة، بنفس المبادئ)
العقد الطرفية لا تزال 🔴/🟡: الهندسة (G) · الضرب/القسمة (M/V) · البيانات (DA) · القياس (Q2,Q3) · الأنماط/التهيئة/المسائل (P,Z,R,S,Ord). بالأولوية: M/V (٥ دول) → G (٣) → DA (٢) → Q (١) → الطرفية.

## ✅ المرحلة ٢ — المحاور الطرفية مُنفَّذة — **محتوى الفصل الأول مكتمل**
كل العقد الطرفية مُلئت إلى ٦/عقدة بالأولوية (M/V → G → DA → Q → الأنماط/التهيئة/المسائل/Ord)، بنفس آلية `SUPPLEMENT` (مولّدات تحسب الأجوبة وتنسّق الأرقام).
- **الأسئلة: ٣٢٧ → ٣٩٦** (المرحلتان معاً: ١٨٠ → ٣٩٦، +٢١٦).
- **التنويع الصحيح لكل محور:** الهندسة (أشكال/مجسمات/عناصر متنوّعة، لا تكرار) · البيانات (مخططات بقيم متنوّعة + الاحتمال يشمل «ممكن») · القياس (أوقات/مبالغ متنوّعة) · الأنماط (متكرّر/متنامٍ/شكلي) · التهيئة (مواضع/فرز متنوّع). حيث الفعل واحد دستورياً → نوّعنا القيم/الأشكال/الأبعاد لا الفعل.
- **الحارس الجديد للحفظ:** كل سؤال **فريد (مطالبة + ودجة)** — للبصري التنوّع في إعداد الودجة لا نصّ المطالبة. مُختبَر في `test_content.py`.
