# مناهج الرياضيات — **الصف الرابع** (مصادر مرجعية دائمة)

**منفصل تماماً** عن متتبّعات صف١ (`README_g1.md`) وصف٢ (`README.md`/`README_s2.md`) وصف٣ (`README_g3.md`). كل ملفات الصف الرابع تُوسَم **«صف4»**، وعقده المستقبلية بسابقة **`g4`** في وحدات `grade_id` خاصة — لا خلط بأكواد صف١/صف٢/صف٣ (مفجّر الكود محلول بالتصفية الصفّية×القُطرية والفهرسة بالمعرّف). **كل عقدة صف٤ مولّدة حياً من يومها الأول** (السجل الديناميكي = عدد العقد المنشورة يفرضه).

## 🛡️ البروتوكول الإلزامي لكل وثيقة (المُتعلَّم عبر ثلاثة صفوف)
1. **تأكيد الدولة + الصف + الفصل** من الغلاف/الحقوق (دروس فخّ «الجزء» السعودي، ومجلّدات الإمارات، وقطر A+B لكل فصل، وأقسام الكويت وسلسلتيها، وفخّ ترقيم الإمارات المعاد — تحفّظ AE-LEN صف٣).
2. **الفهرس/البنية الكاملة + صفحة النهاية** بدليل صفحة. (الفهارس مصوّرة غالباً — تُخرّط بمسح التذييلات/مفردات الوحدات إن لزم.)
3. **إن مصوّر:** ترميز وقراءة بصرية. **أي غموض → فحص المتن، لا تخمين.**
4. المحاور كاملة، والحفظ موسوماً «صف4» + تحديث هذا المتتبّع. **الصفحات الحقيقية بـPyMuPDF (الهارنس يبالغ).**

> **⚠️ خرائط البنى القُطرية المعلومة:** الكويت **قسمان لكل فصل** (1/1+2/1 و1/2+2/2 — مؤكَّد أدناه) · **الإمارات ست كرّاسات/ثلاثة فصول — يلزم جمعها كلها** (درس الكرّاسة المفقودة صف١ + تحفّظ AE-LEN صف٣) · السعودية «جزءان من المقرر» · عُمان كامبردج فصلان · قطر A+B لكل فصل · البحرين جزآن.
