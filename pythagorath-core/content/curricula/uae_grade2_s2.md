**وحدات مرقّمة** (My Math/McGraw-Hill)، كل وحدة: «هل أنا مستعد؟» + مراجعة المفردات + دروس مرقّمة (صفّي + واجباتي المنزلية) + الملاحظة والحساب + مراجعة الاستراتيجيات + ملخّص الوحدة. **مادة خلفية:** منظّمات الأدوات (النماذج WM)، جدول الأرقام الهندية/الغربية، ملاحظات الطالب.

## المحاور والأهداف للفصل الثاني (مستخلَصة — مؤكَّدة بصرياً)
1. **عمليات حتى ١٠٠٠** (و٦، وغالباً ٧ طرح) 🆕 — جمع/طرح ٣ منازل، جمع ١٠/١٠٠ ذهنياً، إعادة التجميع. *امتداد A1/A2/B5 إلى ٣ منازل.*
2. **الزمن** (و٩) 🆕 — قراءة الساعة بكل الدقّات، صباحاً/مساءً، وحدات الزمن (ثانية→عام). *يمتدّ widget الساعة (CLOCK) + وحدات زمن.*
3. **الهندسة** (و١٠) — أشكال ٢د (أضلاع/زوايا)، **مجسّمات ٣د (أوجه/أحرف/رؤوس)**، **كسور-الأشكال/الأجزاء المتساوية**. *يمتدّ G؛ المجسّمات ٣د وكسور-الأشكال مرشّحان.*
4. **القياس** (و١١) 🆕 — الطول (سم/م)، **السعة** (لتر/كوب)، **بيانات القياس (line plot)**. *الطول/السعة يمتدّان Q1؛ line plot صنف بيانات جديد.*
5. **النقود** (و١٢) — الفلس/الدرهم، العملات، قيمة المجموعة. *يمتدّ Q3/money بالدرهم الإماراتي والفلس.*

**ملاحظة فارقة:** الإمارات/ث **لا تُفرد الكسور العددية** (الكسور بصرية فقط ضمن «كسور-الأشكال» و١٠، كقطر) — بخلاف البحرين/السعودية/عُمان اللواتي يفردنها. وتنفرد بوضوح **line plot من بيانات القياس** (كقطر و١٢). **يغذّي قرار المخزون: كسور-الأشكال + line plot مرشّحان مشتركان قويّان.**

**ملاحظة اشتقاق (لاحقة، لا تُنفَّذ الآن):** الإمارات تؤكّد الزمن/الهندسة(٢د+٣د+كسور-أشكال)/القياس(طول+سعة+line plot)/النقود + عمليات ٣ أرقام. تتقاطع مع البقية. **تنبيه: عند البناء، راجِع الطبعة ٢٠١٩–٢٠٢٠ مقابل بقية المخزون، وثبِّت وحدتي ٧–٨ صفحياً.** **لا اشتقاق حتى تكتمل الست** (تبقى الكويت).
