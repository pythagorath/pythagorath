# مناهج الرياضيات — **الصف الثالث** (مصادر مرجعية دائمة)

**منفصل تماماً** عن متتبّعات صف٢ (`README.md`/`README_s2.md`) وصف١ (`README_g1.md`). كل ملفات الصف الثالث تُوسَم **«صف3»**، وعقده المستقبلية بسابقة **`g3`** في وحدات `grade_id` خاصة — لا خلط بأكواد صف١/صف٢ (مفجّر الكود محلول بالتصفية الصفّية×القُطرية والفهرسة بالمعرّف).

## 🛡️ البروتوكول الإلزامي لكل وثيقة (المُتعلَّم عبر صفّين)
1. **تأكيد الدولة + الصف + الفصل** من الغلاف/الحقوق (دروس فخّ «الجزء» السعودي، ومجلّدات الإمارات، وقطر A+B لكل فصل، وأقسام الكويت وسلسلتيها).
2. **الفهرس الكامل + صفحة النهاية** بدليل صفحة.
3. **إن مصوّر:** ترميز وقراءة بصرية. **أي غموض → فحص المتن، لا تخمين.**
4. المحاور كاملة، والحفظ موسوماً «صف3» + تحديث هذا المتتبّع.

> **⚠️ خرائط البنى القُطرية المعلومة:** قطر **جزآن A+B لكل فصل** (مؤكَّد لصف٣ أدناه) · **الإمارات ٦ كرّاسات/٣ فصول — يلزم جمعها كلها** (درس الكرّاسة المفقودة في صف١) · الكويت: تحقَّق أي سلسلة (الجديدة ٢٠٢٥-٢٦ كانت قسمَين لكل فصل في صف١) · السعودية «جزءان من المقرر» · عُمان كامبردج فصلان · البحرين جزآن.
