# Project Summary
**Pythagoras Academy** is an innovative educational platform tailored for Arabic-speaking students. It utilizes advanced AI technologies to deliver personalized learning experiences, including customized lessons, quizzes, and a rewards system aimed at enhancing engagement and academic performance. The project is currently focused on refining its curriculum-driven learning path engine to align with the Oman curriculum for Grades 1-12, ensuring a comprehensive educational journey. Recent updates have introduced a Draft/Preview/Publish workflow, improving administrative flexibility while protecting the student experience, along with a successful real student registration process.

# Project Module Description
The platform consists of the following functional modules:
- **Auth Module**: Manages user authentication and roles.
- **Student Dashboard**: Access to subjects, progress tracking, quizzes, and tasks.
- **Quiz Module**: Facilitates quiz participation and provides feedback.
- **Admin Module**: Manages educational content and analytics.
- **AI Analysis Module**: Analyzes student performance using AI.
- **Parent Dashboard**: Displays student progress metrics.
- **Skills Map Page**: Visualizes skill mastery and recommendations.
- **Adaptive Missions**: Creates personalized missions based on performance.
- **Progress Analytics**: Visualizes mastery and retention metrics.
- **Cognitive Learning Systems**: Includes cognitive games and skill development dashboards.
- **Assessment Dashboard**: Provides adaptive testing and analytics.
- **Decision Engine**: Central system for adaptive decision-making.
- **Diagnostic Assessment Engine**: Connects misconception detection and remediation.
- **Misconception Intelligence**: Manages misconceptions taxonomy and remediation paths.
- **Cognitive Interaction Analysis**: Monitors behavioral signals for decision-making.
- **Assessment State Manager**: Tracks educational state and mastery persistence.
- **Assessment Intelligence Dashboard**: Admin analytics on misconceptions and mastery tracking.
- **Real-Time Decision Engine**: Makes live decisions based on telemetry.
- **Cognitive Telemetry Layer**: Monitors real-time interaction signals.
- **Adaptive Interaction Intelligence**: Adjusts hints and pacing dynamically.
- **Misconception Response Engine**: Addresses rising misconception probabilities.
- **Dynamic Cognitive Load Management**: Adjusts complexity based on overload detection.
- **Real-Time Mastery Tracking**: Updates mastery continuously during interactions.
- **Real-Time Educational Sync**: Manages state persistence and telemetry processing.
- **Curriculum-to-Learning-Path Engine**: Handles curriculum uploads, extracts units and lessons, and generates structured learning paths.
- **Template Inspector**: A lightweight validation tool for cognitive templates to ensure their correct functioning.
- **Student Registration Module**: Allows new students to register without prior authentication.
- **Publish Workflow Module**: Facilitates content validation and publishing through a Draft/Preview/Publish architecture.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, shadcn/ui, recharts
- **Backend**: FastAPI, PostgreSQL
- **Authentication**: Unified authentication system
- **State Management**: React Query
- **AI Service**: deepseek-v3.2 for analyzing student weaknesses

# Usage
1. **Install Dependencies**:
   - For the backend, run `pip install -r requirements.txt`.
   - For the frontend, run `pnpm install` in the frontend directory.
  
2. **Build the Project**:
   - Navigate to the frontend directory and run `pnpm run build`.

3. **Run the Project**:
   - Start the backend server using a command like `uvicorn main:app --reload`.
   - Start the frontend using `pnpm run dev`.
