# public/ assets

Place the official Pythagorath logo files here (exact names):

- `500_برتقالي.png` — orange logo, for light backgrounds (header, light screens)
- `500_ابيض.png` — white logo, for coloured/dark backgrounds (login, orange header)

Until these PNGs are present, `Logo.tsx` shows a branded Tajawal wordmark
("فيثاغورث") as a graceful fallback and upgrades to the image automatically.
